Emberfall is a turn-based elemental card duel that runs offline in a desktop browser from static files. You are the Ember Mage, facing Vex, the Ashen Warden, across a felt table: 30 health each, ember that refills and grows every turn, and a 30-card deck of twelve original cards in four elements — Flame, Frost, Thorn and Tide, each told apart by colour and shape.

Chill Vex with Frost, then strike with Flame to Melt for +3. Thorn cards poison. Ward blocks damage. Vex telegraphs its next card as an intent banner, so every hand is a decision: shield up, or race the damage. First mage to 0 health loses.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Click a card to play it (or press 1–5), END TURN (or Enter) when done, M mutes the sounds. `?shot=title|play|win|loss&seed=7` stages a screenshot scene.
